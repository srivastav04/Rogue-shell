# TinyUnixShell

A miniature Unix shell written in C.

## Features

- Command execution
- Command arguments
- Built-in commands
- `cd`
- `exit`
- `help`
- Output redirection
- Command pipelines
- Multiple pipelines
- Background processes
- Command history
- Process timing
- Exit status

## Requirements

- Linux / Unix-like environment
- GCC
- Makee

## Build

```bash
make
```
